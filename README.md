# Retreats Traveler

Одностраничный сайт международной платформы авторских ретритов и сообщества.
Основатель — Жансая Кайырбекова.

**Стек:** статические HTML + CSS + один файл vanilla JS. Сборки, зависимостей и
бэкенда нет — деплоится как есть на любой статический хостинг.

---

## Запуск локально

```bash
python3 -m http.server 4599
# → http://localhost:4599
```

Либо любой статический сервер (`npx serve`, VS Code Live Server и т.п.).
Просто открыть `index.html` файлом тоже работает, но `<video>` и относительные
пути надёжнее через сервер.

## Дизайн-система (кратко)

Тёмный монохром «alpine at blue hour». Токены — в `css/styles.css → :root`:
графит `#1c1c26` / чернила `#12121a`, единственный акцент — кобальт `#5468ff`
(только primary CTA). Шрифты: Archivo (дисплей, вес 480), Inter (текст),
IBM Plex Mono (метки). Тайпскейл и отступы — на `clamp()`.
Движение: три скорости (micro `.16s` / content `.62s` / cinematic `1.2s`),
полностью отключается при `prefers-reduced-motion`.

## Адаптив

Брейкпоинты: `1180` · `940` (меню → бургер) · `720` · `460`.
Проверено 375 / 414 / 768 / 960 / 1024 / 1280, без горизонтального скролла.
На тач-устройствах фото направлений сразу цветные (ч/б — только под ховер).

## ⚠️ Перед публичным запуском

**Оптимизировать медиа (сейчас ~34 МБ):**
- `assets/hero.mp4` — 850×480, 19 МБ. Пережать в H.264 + WebM, короткий луп 8–15 с, ≤5 МБ.
  Желательно версия ≥1920×1080 (сейчас скрыто размытием).
- `assets/destinations/*.jpg` — по 2–3 МБ, показываются в ~400 px. Ужать до 300–500 КБ
  (или отдать WebP/AVIF). На фото направлений впечатан текст «BALI / HAWAII / …» —
  обрезается через `object-view-box`, но чистые фото без надписей будут лучше.
- `assets/team/*.jpg` — по 1–2 МБ, ужать до ~200–400 КБ.
- Для крупных бинарников можно подключить Git LFS.

**Контент и интеграции (заглушки):**
- Почта `hello@retreatstraveler.com`, соцсети в футере (`#`), реальный телефон/WhatsApp.
- Формы (`#contactForm` и др.) помечены `data-mock` — показывают подтверждение
  без отправки. Подключить к почте/CRM/webhook.
- Программа Бали за дни 4–7 — placeholder.
- Юридическое: политика конфиденциальности, оферта, согласие на обработку ПДн.
- SEO: `og:image`, `canonical`, JSON-LD (`Organization` / `Event`), `sitemap.xml`,
  `robots.txt`, аналитика.

Полный список — в истории обсуждения проекта.

## Деплой

Любой статический хостинг: корень репозитория = корень сайта, билд-команда не нужна.
Все пути относительные, поэтому работает и в подпапке.

### GitHub Pages (настроено)

`.github/workflows/pages.yml` деплоит на каждый push в `main`.
Один раз включить в **Settings → Pages → Source → GitHub Actions**.
Адрес: `https://thevegassi.github.io/RetreatsTraveler/`
(`.nojekyll` отключает Jekyll; `_headers` на Pages не действует — только Netlify/CF).

### Netlify / Cloudflare Pages / Vercel

Подключить репозиторий, build command — пусто, publish directory — `.`
Здесь заголовки из `_headers` (кеш `/assets` на год, security) применяются.
